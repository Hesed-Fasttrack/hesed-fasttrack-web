HESED FastTrack mobile: aligned with the new web dashboard

A guide for bringing the app onto the same design language as the redesigned web dashboard. It keeps the app's navigation (four tabs), the 56px top bar, Plus Jakarta Sans, the semantic tokens and both colour schemes from the October refresh, and borrows the web's structure: a live shipment tracker on Home, a stats strip, dot status pills and calmer list rows.

SurfacesA faint grey canvas (#FAFAFB) with white cards, matching the web, so cards read without shadows. Cards move from 12px to 16px corners; buttons and inputs to 12px. Hairline 1px borders stay.
Home leads with the shipmentThe active shipment card, with route, ETA and the same five-step tracker as the web, is the first thing a customer sees. Swipe between active shipments (dots under it).
Status and listsStatus becomes the web's dot pill. List rows lead with the route (Lagos → London), reference as mono meta, amount and status on the right. Lists stay one bordered container with dividers.
Decision needed: wallet cardThe October refresh moved the app away from solid purple blocks ("purple sparingly"). The new web uses a deep brand-ink wallet card. This mock uses the web card for consistency across platforms. If you prefer the current bordered white card on mobile, everything else here still applies.
